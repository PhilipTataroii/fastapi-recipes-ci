## 📖 О проекте

Cookbook REST API — асинхронное backend-приложение, разработанное на Python с использованием FastAPI и SQLAlchemy.

Приложение предоставляет REST API для создания и просмотра кулинарных рецептов, подсчёта просмотров и сортировки рецептов по популярности.

Учебный проект демонстрирует практические навыки разработки асинхронных API, работы с реляционными базами данных, валидации данных, автоматизированного тестирования и непрерывной интеграции (CI).

## ✨ Возможности

- 🍽️ Создание кулинарных рецептов

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/PhilipTataroii/fastapi-recipes-ci.git
cd fastapi-recipes-ci
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows:

```powershell
.\.venv\Scripts\Activate.ps1
```

В Linux/macOS:

```bash
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск приложения

```bash
uvicorn main:app --reload
```

После запуска API будет доступен по адресу:

http://127.0.0.1:8000/

Таблицы базы данных создаются автоматически при запуске приложения.

## 🔗 REST API-маршруты

| Метод | Маршрут | Описание |
|---|---|---|
| POST | `/recipes` | Создание нового рецепта |
| GET | `/recipes` | Получение рецептов с сортировкой по популярности |
| GET | `/recipes/{recipe_id}` | Получение рецепта с увеличением счётчика просмотров |

### Пример создания рецепта

**POST `/recipes`**

```json
{
  "name": "Margherita Pizza",
  "cooking_time": 30,
  "ingredients": "Flour, tomatoes, mozzarella, basil",
  "description": "Prepare the dough, add the toppings, and bake."
}
```

При успешном создании возвращается HTTP `201 Created`.

### Сортировка рецептов

Рецепты сортируются по следующим критериям:

1. Количество просмотров — по убыванию
2. Время приготовления — по возрастанию при одинаковом количестве просмотров

При каждом успешном открытии отдельного рецепта его счётчик просмотров увеличивается на единицу.

Если рецепт не найден, API возвращает HTTP `404 Not Found`.
